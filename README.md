# Degree Planner

Degree Planner is a web tool for students and advisors alike to explore different scheduling options at a degree wide scale.

## Running This Project Locally

### Prerequisites
- Docker (if you wish to run the devcontainer)

### Setup
1. Clone this repository
2. Install deps with `pnpm install` (the devcontainer will do this for you when building)
3. Run `pnpm dev` to start the dev server on `localhost:3000`
